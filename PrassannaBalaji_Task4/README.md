# Task 4 - Common Network Security Threats

## Internship

Oasis Infobyte Security Analyst Internship

## Objective

The objective of this task is to prepare an original research report on common network security threats. The report explains how selected attacks work, why they matter in real environments, and what practical controls can reduce the risk.

## Threats Covered

- Denial-of-Service and Distributed Denial-of-Service attacks
- Man-in-the-Middle attacks
- IP spoofing
- DNS poisoning and DNS spoofing

## Project Files

| --- | --- |

## Research Methodology

This report was prepared by reviewing credible cybersecurity references, including NIST, CISA, MITRE ATT&CK, CERT/CC, official incident summaries, and reputable security journalism. The content is written in original wording, with citations used to support technical explanations and real-world examples.

## Key Learning Outcomes

- Understood how availability-focused attacks such as DoS and DDoS disrupt business services.
- Learned how MITM techniques can expose credentials, sessions, and sensitive communication.
- Studied how IP spoofing supports reflection and amplification attacks.
- Reviewed why DNS security is important for user trust and reliable internet communication.
- Identified practical mitigation strategies such as traffic filtering, TLS, DNSSEC, network segmentation, and source address validation.
